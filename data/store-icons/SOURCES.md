# Store icons for apps that aren't on Flathub

Each is the publisher's own icon, used only to identify its app in SAINT's Store. Everything else in the Store
comes from Flathub's AppStream data at run time (core/store_art.py).

| File | App | Source (fetched 2026-11-02) |
|---|---|---|
| claude-code.png | Claude Code (Anthropic) | https://claude.ai/apple-touch-icon.png |
| ollama.png | Ollama | https://github.com/ollama.png (Ollama's GitHub organisation) |
| teamviewer.png | TeamViewer | https://github.com/teamviewer.png (TeamViewer's GitHub organisation) |

The logos are their owners' trademarks; Halo uses them only to show which app a Store entry installs.
